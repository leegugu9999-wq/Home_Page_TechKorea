굴뚝 Digital Data Logger

KTE-4000D+ / 6000D+
본 장비는 연돌자동측정시스템의 분석기로부터 계측값과 상태 정보를 수신하여 상위 시스템으로 전송하는 데이터 전송 전용 장비입니다. 2012년 개정된 대기오염공정시험법의 요구사항을 충실히 반영하였으며, 현장의 다양한 요구사항을 유연하게 수용할 수 있도록 설계되었습니다. 또한 Clean-Sys, 총량관리제, 대기 TMS 등 다양한 시스템과의 연계 운용이 가능하도록 여러 통신 프로토콜을 기본 내장하여 폭넓은 호환성과 활용성을 제공합니다.

주요 Hardware 기능

데이터 전송의 안정성과 시스템의 신뢰성을 높이기 위해 다양한 하드웨어 기능을 탑재하였으며, 열악한 산업 현장의 사용환경과 사용자의 편의성을 고려하여 설계되었습니다.
  • System 자원 공유 기능: LCD, I/O, Key, USB 및 기본 통신 Port(COM1, COM2) 등의 시스템 자원을 두 CPU가 공유하여 효율적인 시스템 운용 가능
  • Power Insert 기능: 전원 차단 없이 I/O, CPU 및 통신 보드의 교체가 가능하여 유지보수 편의성 향상
  • 모듈화 설계: 전면 탈부착이 가능한 모듈형 구조를 적용하여 부품 교체 및 A/S 편의성 향상
  • System 전환 기능: 전면 Switch를 통해 Active 및 Non-Active System을 자유롭게 선택하고 전환 가능
  • Multi-Port Self-Test : 통신용 Multi-Port의 자체 진단 기능을 통해 통신 이상 발생 시 각 Port의 정상 여부를 간편하게 확인 가능
  • System 복원 기능: File 손상 등으로 System 오동작 발생 시 저장된 직전 상태로 1분 이내 복원 가능
  • 보안 기능: TCP/IP(LAN) 환경에서 SSL/TLS 및 SSH 등 보안 통신 프로토콜을 적용하여 데이터 전송의 안전성과 시스템 보안성 강화

주요 Software 기능

분석기로부터 수신한 계측값 및 다양한 상태 정보를 한 화면에 집약적으로 표시하며, 10여 년간 축적된 기술력과 다양한 운용 경험을 바탕으로 개발된 수준 높은 프로그램을 탑재하고 있습니다..
  • Multi-Protocol 기능: 다양한 통신 Protocol을 지원하여 Digital 및 Analog 방식은 물론 대기, 수질, 공정 분야의 다양한 시스템과 연계 운용 가능
  • Remote-Check 편집 기능: 환경부 Remote Check 모의시험을 위한 Remote Check Sequence 편집 기능 내장
  • Auto Reset 기능: System 자체 진단을 통해 이상 상태를 감지할 경우 자동 Reset 수행
  • I/O Board Self-Diagnostic 기능: 각 I/O Board별 자체 진단 기능을 내장하여 시스템 상태 및 이상 여부 확인 가능
  • Hot-Swap 기능: I/O Board에 Power-Insert 기능을 적용하여 전원 차단 없이 보드 교체 가능
  • 통신선로 Check 기능: 간편한 점검 기능을 통해 통신 선로의 연결 상태 및 통신 건전성 확인 가능

System 구조 및 Application

Data Logger를 기능별 Module 구조로 설계하여 유지보수 및 A/S 편의성을 높였으며, 긴급 상황 발생 시에도 운영자가 신속하고 간편하게 대응할 수 있도록 하였습니다. 또한 대기 및 수질 측정 분야뿐만 아니라 다양한 산업 현장에도 적용할 수 있도록 확장성과 활용성을 고려하여 설계되었습니다...
  • Module화 설계: 기능별 독립적인 Module 구조를 적용하여 유지보수 및 A/S 편의성 향상
  • 견고한 외함 구조: 19" Rack Base의 알루미늄 Case를 적용하여 내식성과 내구성을 강화
  • 다양한 산업 분야 적용: Stack, 외기관리, 대기전, 기상, 소음측정 및 Process 등 다양한 산업 현장에 적용 가능
